## КОНЦЕПЦИЯ ПРОЕКТА 

## «ЛЕС ЛЮБВИ»<br>

# 1\. Назначение проекта

- Создать отдельный сайт-сервис для регистрации посаженных деревьев и отображения результатов посадок на публичной интерактивной карте.

- Предусмотреть персональные и групповые посадки, именные деревья, а также рекламные размещения, связанные с финансированием посадок.

# 2\. Регистрация и личный кабинет

- Пользователь регистрируется по адресу электронной почты либо номеру телефона. Для регистрации по телефону предусмотрено подтверждение по SMS. Для регистрации по email предусмотрено подтверждение по письму.

- После регистрации пользователь получает личный кабинет и возможность добавлять сведения о посаженных деревьях.

# 3\. Регистрация посаженного дерева

- Пользователь делает фотографию дерева непосредственно в интерфейсе сервиса либо загружает готовое изображение.

- При наличии географических координат в метаданных фотографии система автоматически предлагает использовать их для отметки на карте.

- Пользователь может указать местоположение дерева на карте, дату посадки и породу дерева, затем сохранить карточку.

- Карточка должна содержать сведения о том, кто посадил дерево; поддерживаются посадки группой людей. Это одно универсальное поле которое содержит список ссылок на социальные сети или сайты.

- В карточке есть отметка именно или нет дерево

- В любой момент пользователь может оплатить через карточку посадки размещение именной карточки.

- Данные карточки посадки изменить можно через личный кабинет, но в этом случает будет проводиться повторная модерация.

- В карточке посадки предусмотреть «догрузку» фотографий с указанием даты чтобы можно было следить за историей дерева, как оно растет.

- Карточку не возможно сохранить без указания координат и выбора типа дерева из справочника.

# 4\. Публичная карта и карточка дерева

- На публичной интерактивной карте отображаются точки зарегистрированных деревьев.

- Именные деревья доступны как отдельная возможность заказа и выделяются на карте маркером другого вида.

- При выборе точки открывается карточка дерева со сведениями о месте, дате, породе и человеке или группе, посадивших дерево.

- В карточке предусмотрено единое поле/список ссылок на социальные сети участников посадки: допускаются ссылки на разные сети и несколько ссылок на одну сеть.

- Каждая карточка посадки проходит обязательную модерацию размещения фотографий.

# 5\. Рекламные размещения

- Предусмотрены два формата рекламы: точка, привязанная к определённым географическим координатам, и баннерный элемент поверх карты.

- Рекламная точка ведёт в отдельную карточку рекламы с информацией о посадках деревьев, профинансированных за счёт соответствующей рекламы.

- Карточка рекламы содержит агрегированные показатели посадок с возможностью просмотра каждой посадки, карту всех связанных деревьев, юридическую информацию, сведения о рекламодателе, ссылку на его сайт и маркетинговый текст.
